# Инструкция по переносу одиночного мира на Fabric-сервер

Этот гайд поможет пошагово перенести ваш текущий развитый мир со всеми постройками, фермами и модами на локальный сервер, чтобы играть всей компанией без путаницы с вещами.

---

## ВАЖНОЕ ПРАВИЛО ПЕРЕД СТАРТОМ (Спасение вещей хоста)
Тот парень, который сейчас запускает одиночный мир (Создатель карты), должен зайти в игру, **добежать до базы и сложить абсолютно ВСЕ свои вещи, броню, оружие и опыт в обычный сундук**.
* **Почему:** При переносе мира на сервер, движок создаст для создателя карты чистый сетевой профиль, и он появится голым на спавне. Сложив вещи в сундук, он сможет просто дойти до базы, открыть его и забрать свои ресурсы обратно. Вещи остальных игроков (гостей) сервер найдёт в папке `playerdata` автоматически.

---

## 🛠️ Алгоритм создания сервера

### Шаг 1. Подготовка папки и «движка»
1. Перейдите на официальный сайт **[fabricmc.net/use/server/](https://fabricmc.net/use/server/)**.
2. Скачайте файл установщика **Executable Server (.jar)**.
3. Создайте на Рабочем столе пустую папку и назовите её строго: **`Minecraft_server`**.
4. Перенесите скачанный файл в эту папку и переименуйте его в короткое имя: **`fabric-server.jar`**.

### Шаг 2. Первый запуск и лицензия
1. Внутри папки `Minecraft_server` создайте текстовый файл `start.txt` и пропишите туда команду запуска:
   ```bat
   java -Xmx4G -jar fabric-server.jar nogui
   pause
   ```
   *Примечание: Если стандартная команда `java` выдаёт ошибку версии(то есть у вас не установлена java глобально), пропишите в кавычках прямой путь до `java.exe` из папки вашего лаунчера.
   Например, стандартные пути выглядят вот так:
   * Для Tlauncher - "C://Users/user/AppData/Roaming/.minecraft/runtime/java-runtime-delta/windows/java-runtime-delta/bin/java.exe"
   * Для Legacy Launcher - "C://Users/user/AppData/Roaming/.minecraft/runtime/java-runtime-delta/windows-x64/java-runtime-delta/bin/java.exe"*
2. Переименуйте файл `start.txt` в **`start.bat`** и запустите его двойным кликом.
3. Чёрное окно консоли откроется, создаст файлы и можете его закрывать.
4. Найдите появившийся файл **`eula.txt`**, откройте его через Блокнот, измените строчку `eula=false` на **`eula=true`**, сохраните и закройте.
5. Найдите в папке файл настроек **`server.properties`** и откройте его Блокнотом.
5. Измените следующие строчки:
   * `online-mode=true` ➡️ меняем на **`online-mode=false`** *(обязательно, чтобы пускало через Radmin VPN с TLauncher/Legacy)*.
   * `spawn-protection=16` ➡️ меняем на **`spawn-protection=0`** *(чтобы гости могли открывать сундуки и строить прямо в точке спавна)*.
6. Сохраните и закройте файл.

### Шаг 4. Перенос модификаций
1. Найдите внутри папки сервера созданную папку **`mods`**.
2. Скопируйте в неё **все моды** с компьютера создателя мира (из папки `.minecraft/mods`).
3. **Важно:** Копируйте только серверные моды и моды на контент (блоки, биомы, механики). Чисто клиентские моды на графику, интерфейс или FPS (такие как *Sodium, Iris, Lithium, Xaero's Minimap, ReplayMod*) на сервер закидывать **не нужно** — они должны остаться только в самом Майнкрафте у игроков. **Так они занимают лишнее место в папке сервера, и из-за них могут возникнуть проблемы с сервером.**

### Шаг 5. Перенос вашего огромного прогресса
1. На компьютере создателя мира зайдите в папку `.minecraft/saves/`.
2. Скопируйте папку вашего **настоящего, развитого выживательного мира**.
3. Вставьте эту папку внутрь папки нашего нового сервера `Minecraft_server`.
4. **Обязательно переименуйте** вставленную папку мира в слово **`world`** (маленькими английскими буквами). Сервер запрограммирован искать карту именно с таким названием.

---

## 🚀 Финальная проверка работоспособности

1. Запустите файл **`start.bat`**. Консоль начнёт прогружать Fabric, моды и генерировать чанки вашей настоящей карты.
2. Дождитесь появления заветной строчки в самом низу: **`[Server thread/INFO]: Done! For help, type "help"`**.
3. Создатель сервера запускает свой Майнкрафт ➡️ Сетевая игра ➡️ Прямое подключение ➡️ вводит **`localhost`** и заходит в мир.
4. Убедитесь, что все постройки, сундуки и фермы на месте. Хост локальногом мира может забирать свои вещи из сундука базы.
5. Выйдите из игры и пропишите в чёрной консоли сервера команду **`stop`** (крестиком окно Windows закрывать нельзя, иначе мир может побиться!).

---

## 📦 Интеграция с системой синхронизации

После успешного теста закройте сервер. Теперь ваша папка `Minecraft_server` полностью готова:
1. Нажмите по ней правой кнопкой мыши и заархивируйте.
2. Получившийся архив переименуйте в **`Minecraft_server.zip`**.
3. Закиньте этот ZIP-архив в вашу общую папку **`Minecraft_shared`** на облачном диске (В описании репозитория есть гайд по установке и настройке облака).
4. Рядом создайте пустой текстовый файл `players_ip.txt` (если его там ещё нет).

Всё! Теперь ваш доработанный скрипт на Python автоматически подхватит этот сервер, будет скачивать его за 1 секунду, вести базу IP-адресов по кнопке `3` и делать резервные бэкапы. Приятного выживания!
